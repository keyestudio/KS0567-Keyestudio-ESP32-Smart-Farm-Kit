### 5.1 Sistema de Iluminación



#### 5.1.1 Encender un LED


Abre el código **5.1.1Blink** con Arduino IDE.

```c
#define LED_BUILTIN 27  //Pines del LED

void setup() {
  // inicializa el pin digital LED_BUILTIN como una salida.
  pinMode(LED_BUILTIN, OUTPUT);
}

// la función loop se ejecuta una y otra vez para siempre
void loop() {
  digitalWrite(LED_BUILTIN, HIGH);  // enciende el LED (HIGH es el nivel de voltaje)
  delay(1000);                      // espera un segundo
  digitalWrite(LED_BUILTIN, LOW);   // apaga el LED haciendo que el voltaje sea LOW
  delay(1000);                      // espera un segundo
}
```

Elige la placa **ESP32 Dev Module** y el puerto **COM**, y sube el código.

![51454125](../media/51454125.png)

**Resultado de la prueba:**

El LED parpadea por segundo, porque el io27 de la placa ESP32 emite nivel alto y bajo alternativamente cada segundo.

| Nivel de potencia | Resultado |
| --- | --- |
| HIGH | LED ENCENDIDO |
| LOW | LED APAGADO |

#### 5.1.2 Controlar el LED con PWM


Abre el código **5.1.2PWM** con Arduino IDE.

```c
#define led 27    //Define el pin del LED

void setup(){
  pinMode(led, OUTPUT);  //Establece el pin en modo de salida
}

void loop(){
  for(int i=0; i<255; i++)  //sentencia de bucle for. Aumenta constantemente la variable i hasta 255, sale del bucle
  {
    analogWrite(led, i);  //Salida PWM, utilizada para controlar el brillo del LED
    delay(3);
  }
  for(int i=255; i>0; i--)  //sentencia de bucle for. Disminuye constantemente la variable i hasta 0, sale del bucle
  {
    analogWrite(led, i);
    delay(3);
  }
}
```

Elige la placa **ESP32 Dev Module** y el puerto **COM**, y sube el
código.

![5458448](../media/5458448.png)

**Resultado de la prueba:**

A una frecuencia de señal adecuada, el PWM cambia el voltaje de salida efectivo al cambiar el ciclo de trabajo en un período. En términos sencillos, dentro de un tiempo especificado, cuanto mayor sea el nivel alto que emite el puerto IO, mayor será el valor PWM y más brillante será el LED.

**El módulo LED se encenderá lentamente de oscuro a brillante, y luego de
oscuro a brillante.**

#### 5.1.3 Leer el valor digital del botón


Abre el código **5.1.3Button** con Arduino IDE.

```c
#define ButtonPin 5 //Define el pin del botón como 5

void setup() {
  //inicializa el puerto serie y establece la velocidad de transmisión a 9600
  Serial.begin(9600);
  //Establece el pin en modo de entrada
  pinMode(ButtonPin,INPUT);
}

void loop() {
  //Define un valor como el valor del botón leído
  int ReadValue = digitalRead(ButtonPin); 
  //El puerto serie imprime el valor definido
  Serial.print("El estado actual del botón es: ");
  Serial.println(ReadValue);
  delay(500);
}
```

Elige la placa **ESP32 Dev Module** y el puerto **COM**, y sube el código.

![5458448](../media/5458448.png)

**Resultado de la prueba:**

Abre el monitor serie y establece la velocidad de transmisión en 9600.

Cuando el botón está suelto, el valor es 1; si presionas el botón, se convierte en 0.

El principio del módulo de botón es un circuito controlado por este botón.

Cuando se presiona el botón, el circuito se cierra para que la corriente pase a través del botón a GND, lo que hace que el pin de entrada digital detecte un nivel bajo.

Cuando se suelta el botón, el circuito se corta y el nivel del pin aumenta debido a una resistencia pull-up, lo que hace que el pin digital detecte un nivel alto.

#### 5.1.4 Botón de auto-bloqueo


Abre el código **5.1.4 Self-Locking_Button** con Arduino IDE.

```c
#define ButtonPin 5 //Define el pin del botón
int value = 0;      //Define un valor para determinar el estado del botón

void setup() {
  //Inicializa el puerto serie y establece la velocidad de transmisión a 9600
  Serial.begin(9600);
  //Establece el pin en modo de entrada
  pinMode(ButtonPin,INPUT);
}

void loop() {
  //Define un valor como el valor del botón leído
  int ReadValue = digitalRead(ButtonPin); 
  //Detecta si el botón está presionado
  if (ReadValue == 0) {
    //Elimina el rebote del botón
    delay(10);  
    if (ReadValue == 0) {
      value = !value;
      Serial.print("El estado actual del botón es: ");
      Serial.println(value);
    }
    //Detecta de nuevo si el botón sigue presionado
    //Presionado: ejecuta el bucle; Suelto: sale del bucle al siguiente paso
    while (digitalRead(ButtonPin) == 0); 
  }
}
```

Elige la placa **ESP32 Dev Module** y el puerto **COM**, y sube el código.

![5458448](../media/5458448.png)

**Resultado de la prueba:**

Abre el monitor serie y establece la velocidad de transmisión en 9600.

Cuando presionas el botón una vez, se mostrará 1. Si presionas el botón por segunda vez, el valor se convierte en 0. Ahora, un botón común cuenta con la función de uno de auto-bloqueo.

#### 5.1.5 Usar el botón para controlar el módulo LED


Abre el código **5.1.5 Lighting-System** con Arduino IDE.

```c
#define ButtonPin 5   //Define un pin de botón
#define LED       27  //Define el pin del LED
int value = 0;        //Define un valor para detectar el estado del botón

void setup() {
  //inicializa el puerto serie y establece la velocidad de transmisión a 9600
  Serial.begin(9600);
  //Establece el pin en modo de entrada
  pinMode(ButtonPin,INPUT);
  //Establece el pin en modo de salida
  pinMode(LED,OUTPUT);
}

void loop() {
  //Define un valor como el valor del botón leído
  int ReadValue = digitalRead(ButtonPin); 
  //Detecta si el botón está presionado
  if (ReadValue == 0) {
    //Elimina el rebote del botón
    delay(10);  
    if (ReadValue == 0) {
      value = !value;
      //Detecta el estado del botón, presiona una vez para encender el LED, presiona de nuevo para apagar el LED, en un bucle
      if(value) {
        digitalWrite(LED,HIGH);
      }else{
        digitalWrite(LED,LOW);
      }
    }
    //Detecta el estado del botón de nuevo
    //Presionado: ejecuta el bucle; Suelto: sale del bucle al siguiente paso
    while (digitalRead(ButtonPin) == 0); 
  }
}
```

Elige la placa **ESP32 Dev Module** y el puerto **COM**, y sube el código.
