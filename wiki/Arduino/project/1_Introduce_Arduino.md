## 1. Introductie van Arduino



### 1.1 Wat is Arduino?


Arduino is een open-source elektronicaplatform gebaseerd op eenvoudig te gebruiken
hardware en software. Arduino-boards kunnen inputs lezen - licht op
een sensor, een vinger op een knop, of een Twitter-bericht - en dit omzetten in
een output - een motor activeren, een LED aanzetten, iets publiceren
online. Je kunt je board vertellen wat het moet doen door de programmacode
in de IDE te schrijven en de instructies naar de microcontroller op het
board te sturen. Hiervoor gebruik je de Arduino programmeertaal (gebaseerd op
Wiring), en de Arduino Software (IDE), gebaseerd op Processing.


### 1.2 Installeer de Arduino IDE voor Windows

Arduino officieel: `Software |
Arduino <https://www.arduino.cc/en/software/>`.

Hier klikken we op de ![image-20250416143412683](../media/image-20250416143412683.png) optie voor de eenvoudigste
installatie.

![image](../media/a2.png)

1. Hier nemen we het Windows-systeem als voorbeeld om te introduceren hoe het te
   downloaden en te installeren. Er zijn twee versies beschikbaar voor Windows: voor
   installatie en voor download (een gecomprimeerd bestand, geen installatie nodig).

![a3](../media/a3.png)

Klik op **JUST DOWNLOAD** om de software te downloaden.

2. Sla het .exe-bestand dat van de softwarepagina is gedownload op je harde
   schijf op en voer het bestand eenvoudigweg uit.

![a5](../media/a5.png)

3. Lees de licentieovereenkomst en ga ermee akkoord.

![a6](../media/a6.png)

4. Kies de installatieopties.

![a7](../media/a7.png)

5. Kies de installatielocatie.

![a8](../media/a8.png)

6. Klik op voltooien en start Arduino IDE

![a9](../media/a9-1744785033221-7.png)


### 1.3 Introductie van Arduino IDE 2.0


![image-20250416145828363](../media/image-20250416145828363.png)

**Verifiëren / Uploaden** - compileer en upload je code naar je Arduino
Board.

**Selecteer Board & Poort** - gedetecteerde Arduino-boards verschijnen hier automatisch,
samen met het poortnummer.

**Schetsboek** - hier vind je al je schetsen die lokaal op je computer zijn opgeslagen. Bovendien kun je synchroniseren met de Arduino Cloud en je schetsen ook uit de online omgeving halen.

**Boards Manager** - blader door Arduino- en pakketten van derden die kunnen worden geïnstalleerd. Het gebruik van een MKR WiFi 1010-board vereist bijvoorbeeld het geïnstalleerde Arduino SAMD Boards-pakket.

**Bibliotheekbeheerder** - blader door duizenden Arduino-bibliotheken, gemaakt door Arduino en de community.

**Debugger** - test en debug programma's in realtime.

**Zoeken** - zoek naar trefwoorden in je code.

**Open Seriële Monitor** - opent de Seriële Monitor-tool, als een nieuw tabblad in de console.
